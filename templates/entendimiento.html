01 / Panorama del proyecto

Entender antes de clasificar

Introducción al problema, los datos visuales y la decisión de construir un clasificador de flores mediante una red neuronal convolucional.

Visión por computadorTensorFlow / KerasCinco categorías florales

¿Qué intenta resolver el modelo?

El objetivo es recibir una fotografía y asignarla a una de las categorías florales incluidas en el conjunto de datos. El sistema aprende a partir de ejemplos etiquetados, en lugar de depender de reglas escritas manualmente para cada flor.

01

Una imagen como dato

Una fotografía se representa mediante números. En una imagen RGB cada píxel contiene valores para rojo, verde y azul.

02

Aprender patrones

Los filtros convolucionales aprenden características visuales, desde detalles locales hasta estructuras más complejas.

03

Asignar una clase

La salida genera una puntuación normalizada por clase y la predicción selecciona la de mayor valor.

Las cinco categorías

El código toma las etiquetas de las carpetas del dataset. Las clases utilizadas en este proyecto son las siguientes; su orden definitivo depende de dataset.class_names.

DaisyMargarita
DandelionDiente de león
RosesRosas
SunflowersGirasoles
TulipsTulipanes

Se conservan las etiquetas en inglés porque proceden de los nombres de clase del código.

Del archivo a la predicción

La clasificación no compara necesariamente la fotografía con una imagen idéntica. El modelo transforma la entrada y usa parámetros aprendidos durante el entrenamiento para estimar la categoría.

ImagenFotografía RGB
→
Preparación128 × 128 y normalización
→
CNNConvolución y pooling
→
SalidaPuntuaciones por clase
Alcance: una predicción es una estimación, no una garantía de identificación correcta. Su fiabilidad debe comprobarse con datos que no se hayan utilizado para ajustar los pesos.
