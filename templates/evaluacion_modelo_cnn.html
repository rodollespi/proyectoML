05 / Validación y resultados

Evaluación del modelo

Cómo interpretar accuracy y loss, detectar sobreajuste y completar la evaluación del clasificador sin inventar resultados.

Visión por computadorTensorFlow / KerasCinco categorías florales

Evaluar no es solo mirar accuracy

El código calcula loss y accuracy sobre validación y genera gráficas de ambas métricas durante las épocas. Deben interpretarse juntas y complementarse con un análisis por clase.

Accuracy

Proporción de ejemplos cuya predicción coincide con la etiqueta real. Puede ocultar problemas si las clases tienen cantidades distintas de imágenes.

Loss

Cuantifica el error según la función de pérdida. No equivale al porcentaje de errores, por lo que se interpreta junto con accuracy.

Validación

Permite observar el comportamiento con lotes que no se usan directamente para actualizar los pesos en esa época.

Resultados que deben registrarse

Los valores se dejan pendientes porque no aparecen en la información suministrada. Complétalos tras ejecutar y guardar los resultados reales.

MétricaResultadoCómo obtenerlo
Loss de validación[Completar]Salida de modelo.evaluate(validation_dataset).
Accuracy de validación[Completar]Segundo valor devuelto por evaluate.
Accuracy de entrenamiento final[Completar]Último valor de history.history['accuracy'].
Accuracy de validación final[Completar]Último valor de history.history['val_accuracy'].
Loss de entrenamiento final[Completar]Último valor de history.history['loss'].
Loss de validación final[Completar]Último valor de history.history['val_loss'].

No rellenes estas casillas con valores ilustrativos; usa las cifras de la ejecución que documentarás.

Cómo leer las curvas

La evolución de las métricas ayuda a identificar patrones, pero no demuestra por sí sola que el modelo funcione igual con fotografías externas.

Aprendizaje consistente

Si loss disminuye y accuracy aumenta en entrenamiento y validación, puede ser señal de aprendizaje útil. Revisa también el comportamiento final.

Posible sobreajuste

Si el rendimiento de entrenamiento mejora mientras validación empeora o se estanca, puede existir sobreajuste o diferencia entre conjuntos.

Posible subajuste

Si ambos conjuntos rinden mal, puede que arquitectura, datos, preprocesamiento o entrenamiento sean insuficientes.

Evaluación por categoría

La matriz de confusión permite observar qué clases se confunden. Precision, recall y F1 describen el comportamiento de cada clase.

IndicadorPregunta que responde
Matriz de confusión¿Qué categorías se predicen correctamente y cuáles se confunden?
Precision por claseDe las imágenes asignadas a una clase, ¿qué proporción pertenece realmente a ella?
Recall por claseDe las imágenes reales de una clase, ¿qué proporción fue detectada?
F1 y macro-F1¿Cómo se equilibra precision y recall entre las clases?
Importante: el código disponible evalúa el conjunto denominado validación. Para estimar generalización final es preferible reservar un conjunto de prueba independiente, que no se utilice para elegir ajustes.
